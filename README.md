# NovaOS Debian 13

Plain Debian 13 on the NovaOS kernel and boot chain for RK3399 scopes (DHO800/DHO900, MHO900). There is no oscilloscope
application in it: this is an operating system to build on, and the scope does not acquire under it.

Not made or endorsed by Rigol. Rigol is named only to say which scopes this fits. Writing to the card is at your own
risk, with no warranty: back it up first.

Download: [the latest release](https://github.com/Bradyok/novaos-debian13/releases/latest), [debian13-1ccc061698a0](https://github.com/Bradyok/novaos-debian13/releases/tag/debian13-1ccc061698a0).
Its README says what each file is, how to install it, what was tested and what was not, and where the source of everything in it is.
